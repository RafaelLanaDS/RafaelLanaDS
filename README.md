## Sobre mim

Sou desenvolvedor Front-End, criativo e apaixonado por tecnologia, com **React e JavaScript** como principal stack. Comecei de forma autodidata e dei um salto no estágio na **DevRocket**, onde entreguei projetos reais que chegaram à produção.

- Mantenho em produção o **Agenda Barber**, sistema de agendamento usado por uma barbearia.
- Desenvolvi do zero um tema de e-commerce para o segmento automotivo nas plataformas **Tray** e **Bagy**, e integrei APIs REST (JSON).
- Dei suporte técnico a lojistas por videochamada, WhatsApp e chamadas em grupo.
- Uso **Copilot, Claude Code e Cursor** no desenvolvimento e estou sempre testando novas formas de programar com IA.

Acredito que um bom desenvolvedor não é só quem escreve código limpo, mas quem entende o problema do usuário e entrega a melhor solução possível.

## Projeto em destaque

### [Agenda Barber](https://rafaellanads.github.io/Barber) &nbsp;`Em produção real`

Sistema de agendamento em uso ativo pelo Stúdio Valtinho Barber.

- **React** para a interface responsiva e o fluxo de agendamento
- **Firebase** para banco de dados em nuvem, autenticação e regras de acesso, com dados em tempo real
- **JavaScript** para a lógica de disponibilidade de horários e a validação dos agendamentos

[Ver o projeto](https://rafaellanads.github.io/Barber) &nbsp;|&nbsp; [Ver o código](https://github.com/RafaelLanaDS/Barber)
